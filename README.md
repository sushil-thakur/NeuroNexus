# Google Form-like Web Form (HTML + CSS)

This is a simple and clean web form inspired by Google Forms, built using only **HTML and CSS** (no JavaScript). It collects user information such as name, contact details, company, department, and gender.

## ✨ Features

- Full Name (Text input)
- Contact Number (Phone input)
- Address (Multiline textarea)
- Company Name (Text input)
- Email Address (Email input)
- Department (Dropdown menu: HR, Sales, Development, Marketing, Others)
- Gender (Radio buttons: Male, Female, Prefer not to say)
- Submit Button

### 💡 Bonus Features
- Hover effect on the Submit button
- Distinct form background color
- Minimalistic box-shadow for a modern look
